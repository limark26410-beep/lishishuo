# 出片工具 · 同事上手文档

> 一个仓库，两条出片流程：**历史说**（纪录片式口播）和 **白酒短剧**（人物对话式）。
> 跟着本文档 5 分钟跑通，之后就能批量出片。

---

## 一、这是什么

| 流程 | 入口命令 | 用途 | 输入 |
|------|---------|------|------|
| 历史说（纪录片式） | `run.py` | 文史口播/旁白 + 生图 + Ken Burns + 字幕 | `script.txt` + `prompts.json` |
| 白酒短剧（人物对话式） | `run_baijiu.py` | AI 视频 + 多角色配音 + 对话字幕 | `project.json` |

两条流程互不影响，各跑各的。

## 二、环境准备（一次搞定）

```bash
# 1. 克隆
git clone https://github.com/limark26410-beep/lishishuo.git
cd lishishuo

# 2. Python 虚拟环境 + 依赖
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 3. ffmpeg（必须装真实版，Mac 用 brew）
brew install ffmpeg
```

> 依赖清单：pyyaml / pillow / edge-tts / requests / python-docx / aiohttp / numpy / openpyxl

## 三、填 API Key（谁用谁注册，各填各的，别共用账号）

```bash
cp .env.example .env
# 然后编辑 .env，填下面的 key（空着就不启用对应功能）
```

| Key | 干什么 | 去哪注册 | 免费/付费 |
|-----|--------|---------|-----------|
| `DASHSCOPE_API_KEY` | AI 生图 / 图生视频 | 阿里云百炼 bailian.console.aliyun.com | 少量免费，wanx 0.14元/张 |
| `DEEPSEEK_API_KEY` | 写稿 / 提示词 | platform.deepseek.com | 极便宜（一篇稿几分钱） |
| `ZHIPU_API_KEY` | AI 视频（文生视频） | open.bigmodel.cn | ✅ flash 免费 / cogvideox-3 1元/段 |
| `DOUBAO_TTS_KEY` | 配音（可多角色） | console.volcengine.com（语音合成） | 有免费额度 |
| `ARK_API_KEY` | 豆包大模型（备用） | console.volcengine.com/ark | 有免费额度 |
| `PEXELS_API_KEY` | 抓视频/图片素材 | pexels.com/api | ✅ 免费 |

**零成本跑通**：智谱 flash（AI 视频）+ edge-tts（配音，无需 key）+ 本地素材，一分钱不花。

## 四、素材库路径（默认即可，也可改）

- 默认素材库：`~/Desktop/历史说素材`（共享空镜/片头背景/bgm/系列归档都在下面）
- 改法 A：编辑 `config.yaml` 的 `paths.material_root`
- 改法 B：`export LISHISHUO_MATERIAL_ROOT=/你的素材库`

> 仓库根目录已自动定位（clone 到哪都能跑），不用改代码。

## 五、快速出片

### 5.1 历史说（纪录片式）

```bash
# 准备一期的输入：episodes/001/script.txt（稿子）+ prompts.json（生图提示词）
./venv/bin/python run.py --episode 001

# 常用参数
./venv/bin/python run.py --episode 001 --title "主·副" --series 系列名 --name 归档名
./venv/bin/python run.py --episode 001 --canvas portrait   # 竖屏 1080x1920
```

### 5.2 白酒短剧（人物对话式）

一个项目目录 = 一集对话短片。目录里放一个 `project.json`：

## 六、本地素材（省掉线上生图）

**有本地素材就直接用本地，不花生图钱：**

```bash
# 本地图片（跳过线上生图）
./venv/bin/python run.py --episode 001 --images-dir /你的图片目录

# 本地视频素材（走视频混剪，不生成图片）
./venv/bin/python run.py --episode 001 --video-dir /你的视频素材库

# 手动把图片放进 episodes/001/images/，再跳过生图
./venv/bin/python run.py --episode 001 --skip-images
```

## 七、常见问题

**Q1：跑历史说报「没有可用的生图结果」？**
没配 `DASHSCOPE_API_KEY` 或没生图额度。要么填 key，要么用 `--images-dir` 本地图片。

**Q2：智谱视频生成报 429 / 网络错？**
免费档有并发限制，脚本已内置限速重试；网络报错会自动重连。若仍失败，检查网络或换 `cogvideox-3`。

**Q3：字幕/配音对不上？**
配音和字幕同源生成，正常是同步的。若不对，重跑一次（`--skip-images`）。

**Q4：想改配音音色/语速？**
历史说：config.yaml 的 `tts.voice` / `tts.rate`；白酒：project.json 里每个 scene 的 `voice` / `rate`。

**Q5：同事之间会共用额度吗？**
不会。各填各的 `.env` key，谁用谁扣自己的额度。

## 八、目录结构

```

  config.yaml          # 全配置（素材库路径/编码器/字幕字体）
  run.py               # 历史说主流程
  run_baijiu.py        # 白酒短剧流程

  episodes/{期号}/     # 历史说每期
  lib/                 # 工具库
  tools/               # 批量出片脚本

```
