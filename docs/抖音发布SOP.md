# 抖音发布 SOP（历史说）

> 适用：历史说系列成片发布到抖音创作者中心
> 入口：`https://creator.douyin.com/creator-micro/content/upload`

## 三条硬门槛

### 1. 必须等转码结束再点发布

- 上传后进度条会从 0% 走到 99%，**99% 不等于完成**。
- 必须等到：**进度条消失**，且页面出现 `<video>` 元素。
- 看到 99% 就点发布 → 抖音静默拒绝：不报错、作品数不增加。

### 2. 封面上传框只认真人拖拽

- 脚本注入文件前端不认，必须人工操作。
- 路径：作品管理 → 继续编辑 → 点封面槽里的图 → AI 封面编辑器 → 上传 → 完成。
- 竖封面槽和横封面槽分别操作。

### 3. 横封面必须 4:3 横版图

- 竖封面：**765×1024**（3:4）
- 横封面：**1024×765**（4:3）
- 横槽传竖图会错位。

## 发布流程

1. 上传视频，等转码完成（进度条消失 + `<video>` 出现）。
2. 填标题（≤30 字，格式 `人物·称号`）、简介（钩子 + 话题）、合集。
3. 封面：按上面第 2、3 条人工上传竖版、横版。
4. 自主声明：选 **「内容由AI生成」**，不要选「内容含营销推广信息」。
5. 定时发布：一天一条，固定 **11:25**。
6. 点发布。
7. 回作品管理核对：**作品数 +1**，列表里能看到这一条。

## 其他坑

- 合集下拉会一直浮在页面上挡住点击，选完要隐藏 `.semi-popover`。
- 浏览器（Chrome 调试实例）跑久了会卡死，重启即可。
- 发布后必须核对作品数，不能只看“发布成功”提示。

## 代理分流

| 目标 | 线路 |
|---|---|
| 抖音 / `*.douyin.com` / `*.bytedance.com` | **直连，绝对不能走代理**（IP 变动触发风控） |
| Wikimedia Commons | 走代理（国内直连不通） |
| Pexels | 走代理 |
| Gemini | 走代理 |

Windows 代理绕过列表已加入抖音/字节域名；`scripts/fetch_city_images.py` 默认走 `http://127.0.0.1:7897`。

## 封面制作

用 **Gemini 直接出成品图**（大字主标题、小字副标题、红色印章一起画进画面），不要让程序后期叠字。

提示词模板见 `历史说_换Windows电脑交接说明.md` 第十节，只替换人名/称号/场景；横版把第一句改成“同系列的横版封面图（4:3 横构图）”。

## 发布前检查

- [ ] 正式成片已通过 `verify_sync.py`（命中率≥90%，超 0.8s 条目为 0）
- [ ] 竖封面 765×1024、横封面 1024×765 已准备好
- [ ] 浏览器已登录 `creator.douyin.com`（抖音客户端登录不算）
- [ ] 代理分流正常：抖音直连，Commons/Pexels/Gemini 走代理
- [ ] 标题、简介、合集、自主声明已填
- [ ] 转码已完成（进度条消失 + `<video>` 出现）
- [ ] 发布后作品数 +1
